# AGENTS

## Proyect
- Este proyecto debe hacerse en español
- Se creara una API REST con Express que sirva para que un frontend haga las consultas pertinentes
- Se deben realizar una serie de funciones extras
### API
- ISteamUserStats (API oficial de Steam) 
- ISteamUser (API oficial de Steam)



## Runtime
- Node 18+ is required (Express 5 engine >=18 in package-lock.json).

## Commands
- Run the server with `npm start` (script is `node index.js`).
- `npm test` is a stub that exits 1 (no tests configured).

## Entrypoint
- The Express app is in `index.js` and listens on port 3000.

## Docker
- The Docker build file is named `dockerfile` (lowercase); use `docker build -f dockerfile .`.
